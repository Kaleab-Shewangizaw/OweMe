# OweMe

OweMe is a simple and modern debt & borrowing tracker that helps users keep track of money they lend, borrow, and repay without confusion.

## Features

- Track borrowed and lent money
- Record repayments
- View transaction history
- Simple and clean UI
- Real-time balance overview

## Tech Stack

- React Native
- Node.js
- PostgreSQL

## Goal

OweMe was built to simplify personal debt tracking and make financial interactions easier to manage.

## Status

Currently under active development.
